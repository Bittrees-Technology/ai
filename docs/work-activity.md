# Work activity

The board groups existing research runs and this Mac's central workflow steps into
Backlog, Ready, In progress, Review, Blocked and Done. List view retains the same
cards. Research cards expand to the existing source/model/CRM evidence view.

Central cards use the original job, run and workflow IDs. Pending local output is
not completion: a card reaches Done only after the central completion response
has been validated and journaled. A completed step is distinct from a completed
workflow or an authorized successor. Source links use the workflow ID saved with
the receipt, so changing connections cannot relabel old work. Legacy receipts
without a workflow ID remain visible without a guessed link.

This is a local projection, not a mirrored central queue: it shows the current
job and last confirmed completion. Follow the central run link for the complete
role-based run and its permitted actions. Local reads add no remote calls, grants,
enrollment, schedules or native network permissions. The current device must
still be enrolled and explicitly authorized before central execution can work.

Refreshing pauses while the page is hidden and does not overlap earlier reads.
Partial failures retain prior observations with an out-of-date warning. Existing
Roles, source checks, leases, operation IDs and source approval controls remain
authoritative; the board does not implement independent drag-to-complete state.
