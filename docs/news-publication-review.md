# Reviewed public News editions in the Mac companion

The companion now exposes the reviewed-publication backend through authenticated local routes and the News connection panel. Normal Mac startup supplies its owner-bound encrypted journal. Publication requires an existing News key with publish scope and a separate confirmation for each complete reviewed edition. Saving a key or approving a private story edit does not approve publication. No personal key or live publication was used for this implementation.

## Review and operation history

“Review public edition” loads the source’s exact public name, description, destination and navigation, front-page stories and every named feed. No feed is silently omitted, shortened or paginated out of the review. Story headings and summaries use the same translation precedence as the current News renderer; original text, excerpts, briefing previews, attribution, dates and every additional public story field are available in explicitly labeled details. Full source links are visible. Stored feed names and live navigation names are both shown. These are the reviewed snapshot’s public data; the published page’s layout may differ.

A separate unchecked acknowledgement covers every section, the public audience and possible later inclusion by existing subscriptions. The button stays disabled without consent or when the source reports blocked content. The server rechecks the exact review, source permissions and two-minute deadline before persisting and dispatching the approved intent. UI scope checks are guidance; source and local server checks remain authoritative. The flow does not generate briefings, change source sharing, invoke delivery or alter schedules.

Focus loss, hiding/unmounting the view, refresh, deadline expiry or explicit cancellation clears visible content and consent. Cancellation targets one review ID; a delayed cancellation cannot invalidate a newer review. A review response arriving after the view was hidden is discarded and its ID is cancelled. Once confirmation is sent, hiding the view cannot undo a source commit. Late results are hidden and never retried; the retained local journal remains recoverable through an explicit history read.

“Load publication history” reads only the local owner’s records, without calling News. Summaries contain names, destinations, source identity, timestamps and receipt status; the full exact approved payload is loaded only when a record is opened. The list and opened record clear on focus/session loss. History remains available without a saved News key. “Check publication receipt” requires a valid read key for the same News account and invokes only a source receipt lookup. A recorded receipt is historical: it does not claim current public visibility or delivery. An absent receipt or empty history does not prove an in-flight request failed.

Deleting one local record requires a separate unchecked acknowledgement that tracking is being forgotten. It cannot withdraw the source edition, cancel an accepted request or delete saved backup copies. Deletion is serialized with connector operations; all-data deletion also invalidates a held review. Records are included in the existing “Export my local data” action under Data controls. No bearer credential enters history, exports or the public payload. Retention remains until explicit deletion; no automatic journal cleanup was added.

## Interface design

The panel extends the companion’s existing Avenir/Avenir Next type, slate text `#183945`, blue-gray surface `#edf3f6`, white `#ffffff`, green action `#28685c` and blue focus `#29658b`. Left-aligned edition content occupies one column with visible section boundaries, followed by its consent control. History is a separate section below. The emphasis belongs to the content being made public, rather than a dashboard statistic or decorative illustration. Secondary public metadata uses expandable details; all front-page and named-feed stories are present by default. Narrow layouts stack metadata, wrap full links, preserve exact text and retain visible keyboard focus. No new font download or motion was introduced.
