# Reviewed Mac private task delivery

The companion Connections screen now opens a separate private task delivery panel on request. Opening loads bounded local connection and accepted-task/reply metadata. It does not poll the relay, run a task, prepare a reply or send a message.

Choose an active saved connection and review one incoming-task check. The native receiver still authenticates the envelope, checks current independent task permission, saves admission durably and acknowledges the exact relay message. Acceptance history identifies the original operation and browser after reopening; it does not prove permission remains active or work is complete.

An acceptance reply or completed result is prepared separately for one historical task/browser. Result preparation requires completed work and separate result-sharing consent in the native controller. Preparing retains encrypted ciphertext locally. Sending requires another review of the exact saved reply, revision, browser, connection and deadline. Every explicit retry uses the original saved reply and refreshed revision; a storage receipt cannot claim the browser authenticated or opened the result. Stopping retries is available offline and keeps local history; it cannot recall a sent message or cancel task work.

Each review starts unchecked, expires within two minutes and the current connection/reply deadline, checks wall and monotonic clocks, and is consumed once. Confirmation reloads the exact metadata snapshot before calling the native action. Private review state is retained separately from its display copy. Blur, hiding, Escape and closing discard the review and fence the native transport scope. Late responses are suppressed; an action already committed cannot be undone. An uncertain result clears local selection and requires a fresh history read and new review; no automatic retry is added.

Validation: six focused controller tests exercise the actual native synthetic controllers, durable reply store, admission, preparation, delivery, lost-response retry, stale revision rejection, clock expiry, cancellation during held transport and offline stopping. The full local engine suite contains 667 passing cases; typechecking, production/fixture builds and unchanged contract export pass. Four UI scenarios (12 cases across Chromium/Firefox/WebKit) use the shipped React panel and state controller with an explicit synthetic local API fixture. They cover explicit opening, separate reviews, uncertain-send recovery, hidden/stale work and offline stopping, and produce 18 previews. These browser runs and visual acceptance are pending CI. Real browser-to-native HTTPS transport is independently covered by the retained end-to-end delivery suite; the UI fixture does not substitute for those authority tests.

No installed app replacement, live policy activation, personal Keychain access, scheduler or model change is included. The companion runs independently on the Mac. Acer news jobs and their model/runtime remain unchanged.
