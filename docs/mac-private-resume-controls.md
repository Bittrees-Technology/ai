# Mac resume permission controls

Design: preserve the companion palette: ink #183945, canvas #edf3f6, white #ffffff, border #aabec5, focus blue #29658b, action green #28685c. Avenir/Avenir Next carries headings and body; existing size hierarchy and focus styles remain. A left-aligned section beneath the selected task’s actions contains saved choices, browser and duration selection, then one explicit review. No motion or new card system. Exact task, model identity, paired browser fingerprint and expiry make this permission distinguishable from conversation sharing. Review against the brief: reuse the established Mac workspace, with task-bound controls rather than a generic settings page. Long identifiers wrap and each field has a visible label.

Saving permits one encrypted resume of this exact paused task and model; it does not resume the task or send permission to a browser. Browser offer/command transport remains a separate unfinished work package. This UI does not enable the startup feature flag.

Reviews clear on focus loss, hidden document, Escape, selected task/status/revision change, form changes, expiry and unmount. Confirmation requires a separate acknowledgement. Lost responses are not retried. Revocation remains available for a saved grant after the task revision changes. No task text is submitted by these controls. Acer news processing is unchanged.

Local validation: 926 tests pass (six new controller regressions), typecheck, production builds and contract export pass. Three browser scenarios use the actual built dashboard with synthetic routed HTTP across Chromium, Firefox and WebKit: exact review/save/revoke after task revision change; Escape/focus/task-switch and late-response invalidation; lost confirmation without retry. Browser execution and screenshots are pending disposable GitHub CI. No local browser automation was used. Visual acceptance and integration remain unproven until the reports and screenshots are reviewed; the prior shared delivery regression still gates merging.
