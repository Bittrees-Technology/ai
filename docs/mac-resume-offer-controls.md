# Mac resume offer controls

Design plan: retain Avenir/Avenir Next, left alignment and the existing task-detail hierarchy. Palette: ink #183945, canvas #edf3f6, surface #ffffff, border #aabec5, focus #29658b and action #28685c. Put saved offers beneath the selected task’s resume permissions. Show task/model/browser identity and expiry in the existing review layout; use one unchecked acknowledgement immediately beside its label. Long identifiers wrap on narrow screens. No motion or new navigation. Reviewing this plan against the brief keeps the permission and encrypted-file steps visibly distinct within the established Mac workspace.

Create/download/stop are separate reviewed actions. Downloads contain only the validated encrypted offer, never task text. Browser import and remote resume remain unfinished and the screen says so. A refreshed permission revision or another parent permission action unmounts the offer panel, discarding pending reviews and late responses. Task changes, blur, hidden document, Escape and review expiry do the same. Existing stopped/old offers remain visible for history. Stopping a download does not revoke the separate resume permission.

Local verification: 948 tests pass, including six offer-panel cases covering exact acknowledgement, lost/late replies, scope/destination changes, monotonic expiry, offline stopping, changed task revisions/status, and changed model identity. Type checking and both production builds pass. Browser download interactions, narrow-screen visual acceptance and disposable CI remain pending. This package is not integrated or activated.
