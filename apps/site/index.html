Bittrees AI

Run AI models on your Mac. Review generated drafts and manage saved context with links to its sources.

App connections require permission. Changes to connected apps require review before submission.

Download the Mac preview

Apple Silicon, macOS 13 or newer. Not Apple-notarized. Models downloaded separately.

Installation

  1. Download and verify

    Follow the download verification guide to check the file’s source and checksum. This is a development preview, not a notarized release. Automatic updates are not available.

  2. Install a local model

    Install Ollama and download a compatible model separately. Model size affects memory use and speed. Check generated answers against their sources.

  3. Configure app access

    Start with sample data. Each app connection requires its own setup and permissions for reading or publishing records.

This development download is not signed with Apple Developer ID or notarized by Apple. After verifying the download, follow Apple’s instructions for opening an app you trust if macOS blocks it. Device policies may prevent opening it.

Read the Mac setup guide before first launch. Back up your existing app and data before upgrading, and retain your original Keychain keys.

The current preview supports Apple Silicon Macs. Windows and Linux versions are planned. Remote access is not available from this site.

Data and privacy

Local content

Tasks and saved context stay on your Mac until you delete them. Export and deletion controls are available in the app. Keep your recovery key: Bittrees cannot recover it for you.

Connected apps

Content you publish to another app follows that app’s retention rules. Independent security review and broader user testing of this preview are not complete.

This page has no sign-in, task submission or analytics. Its documentation and support links open GitHub or Apple Support.

Support

View issues or report a problem. Include your app version and steps using sample data. Reports are public: leave out messages, credentials, pairing details and recovery codes.
